A self-built application tracker to manage my own job search: a **React** front end backed by **Supabase**, with AI-powered intake that uses the **Claude API** to parse job postings and pre-fill application details instead of manual data entry.

Built out of a direct need rather than as a portfolio exercise — a small full-stack side project that also gave me hands-on time with the Claude API outside of the LogiMind agent stack.

**Stack:** React, Supabase, Claude API
